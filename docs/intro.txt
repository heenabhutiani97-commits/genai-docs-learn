## HOW GENAI Works???

In GENAI -- firstly we pass our input as text, audio, video, image etc. that is said as prompt to the model which will give us the output that is being called as output.

If we will pass the same prompt to the model even then output can vary .. how it is possible.....

Our GENAI model is trained on HUGE DATA... and also when we are chatting with them, the model is NOT necessarily being trained again from every conversation.

This is how it works when we feed the prompt to understand that input:

input ----> tokens ----> token IDs ----> LLM

Same works in reverse order to generate outputs:

LLM ----> token IDs ----> tokens ----> text ----> outputs

---

## TOKENIZATION:

Tokenizer is a process when we feed any input or prompt -- this tokenizer will break the input into smaller chunks, that means it will split the input and then these tokens will be converted into token IDs i.e. numbers because these models work better with numbers than raw text.

So:

input --> tokens --> token IDs --> LLM

The token IDs are numerical representations that the model can process.

---

## How does the model decide the output?

The model predicts the next possible token based on probability distribution.

There can be multiple possible tokens that can come next. The model uses probability to decide which token to generate.

But still there is randomness applied to the generation process, that's why even for the same input we can have different outputs.

## EMBEDDINGS:

It is basically used so that we can find the relation between the words -- if the words are connected to each other or not.

Tokens are basically conversion of text into numbers so that LLM can process the inputs, but with the help of embeddings we find the relation or can say context/meaning in the text.

Embedding represents the text as a vector (a list of numbers).

Related words or text generally have vectors which are closer/similar to each other, while unrelated text will have vectors which are less similar.

For example:

"dog"    → [0.21, -0.45, 0.87, ...]
"puppy"  → [0.24, -0.41, 0.82, ...]
"car"    → [0.91,  0.02, -0.73, ...]

Here "dog" and "puppy" will generally have more similar embeddings because their meaning/context is related.

So:

Tokenization → converts text into tokens and token IDs so that the model can process the text.

Embeddings → convert text into vectors so that we can represent and compare the meaning/semantic relationship of the text.
